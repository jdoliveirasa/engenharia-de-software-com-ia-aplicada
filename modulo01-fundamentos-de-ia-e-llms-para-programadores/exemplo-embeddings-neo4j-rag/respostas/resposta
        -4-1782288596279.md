A normalização de dados é uma etapa fundamental que acontece sempre que trabalhamos com machine learning ou processamento de máquina. Basicamente, ela consiste em converter e ajustar os dados para que a máquina consiga aprender padrões, prever situações e até recomendar produtos de forma eficiente.

Para facilitar o entendimento, imagine que a normalização serve para colocar os dados em uma escala comum. No contexto fornecido, vemos um exemplo prático usando a idade de pessoas para transformá-la em um valor normalizado. 

Veja como funciona o cálculo apresentado:
Se temos idades que variam entre 25 e 40 anos, a normalização transforma esses valores em números entre 0 e 1. Por exemplo:
*   **Ana (25 anos):** $(25-25)/(40-25) = 0$
*   **Erick (30 anos):** $(30-25)/(40-25) = 0.33$
*   **Carlos (40 anos):** $(40-25)/(40-25) = 1$

Essa etapa de normalização e conversão dos dados para tensores é o que permite que a rede neural processe as informações corretamente através de suas conexões e cálculos, permitindo que ela extraia padrões e, ao final, entregue uma resposta (como a probabilidade de um perfil pertencer a categorias como "Premium", "Medium" ou "Basic").
