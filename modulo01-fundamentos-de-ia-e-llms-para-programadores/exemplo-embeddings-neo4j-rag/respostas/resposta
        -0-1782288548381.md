De forma bem simples, **Tensores** são a base do funcionamento do TensorFlow.js. Eles podem ser entendidos como vetores ou listas em JavaScript, mas com uma característica essencial: seu conteúdo deve ser representado exclusivamente por **números**. Isso é necessário porque os algoritmos de machine learning aprendem a partir de padrões de dados numéricos.

Um ponto muito importante para nós, desenvolvedores JavaScript, é que o TensorFlow.js **não entende objetos ou instâncias primitivas** da linguagem. Por isso, se você tiver dados em formatos comuns (como objetos), precisará convertê-los para a estrutura de um Tensor.

**Como isso funciona na prática?**

Imagine que você tem um array de pessoas com diferentes propriedades, como no exemplo abaixo:

```javascript
const pessoas = [ 
  { nome: "Erick", idade: 30, cor: "azul", localizacao: "São Paulo" }, 
  { nome: "Ana", idade: 25, cor: "vermelho", localizacao: "Rio" }, 
  { nome: "Carlos", idade: 40, cor: "verde", localizacao: "Curitiba" } 
];
```

Como o TensorFlow.js não consegue processar o texto "azul" ou "vermelho" diretamente, precisamos transformar essas informações em números. Uma maneira de fazer isso é criando uma tabela onde atribuímos "1" para a propriedade que está ativa e "0" para as demais.

Veja como a representação das cores preferidas seria transformada em um formato que o Tensor compreende:

| | azul | vermelho | verde |
| :--- | :---: | :---: | :---: |
| **Erick** | 1 | 0 | 0 |
| **Ana** | 0 | 1 | 0 |
| **Carlos** | 0 | 0 | 1 |

Dessa forma, transformamos dados qualitativos (cores) em dados numéricos, permitindo que o algoritmo identifique padrões e determine, por exemplo, em qual categoria uma nova pessoa se encaixaria com base no histórico do banco de dados.
